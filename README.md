## 🧠 Architecture & Engineering Principles

```text
Business problem
      ↓
Discovery & constraints
      ↓
System boundaries
      ↓
Data + integration architecture
      ↓
Implementation
      ↓
Observability & failure handling
      ↓
Performance + iteration
```

I optimize for:

- **Maintainability** — software should be understandable after the original developer leaves.
- **Operational reliability** — integrations need retry strategies, observability, and explicit failure modes.
- **Scalability** — architecture should accommodate growth without unnecessary premature complexity.
- **Performance** — frontend speed and backend efficiency are product features.
- **Business alignment** — architecture decisions must reflect actual operational and commercial constraints.
- **Incremental delivery** — ship valuable systems in testable, observable stages.
